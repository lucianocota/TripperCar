# 🏗️ Tripper Car Scheduling Problem (TCSP)

This repository presents the research and implementation related to the Tripper Car Scheduling Problem (TCSP). It includes mathematical programming models, benchmark test instances, experimental results, and supporting research materials.

---

## 🧠 Problem Overview

The tripper car is a machine used in iron ore processing plants to distribute material transported by conveyor belts among a set of silos. The Tripper Car Scheduling Problem (TCSP) consists of determining the sequence of equipment positions while maintaining the material levels in the silos within appropriate operating conditions, thereby contributing to the stability of downstream processes.
